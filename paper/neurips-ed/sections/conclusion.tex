JaxARC provides an accelerator-native RL environment that makes large-scale experimentation on ARC practical. On an H100 GPU it achieves over 100 million steps per second, more than three orders of magnitude faster than the prior ARCLE environment. We used this throughput to build the first multi-algorithm RL baseline benchmark for ARC, evaluating PPO, DQN, PQN, and REINFORCE across twelve task subsets from ARC-AGI and ConceptARC. The results establish a stable algorithm hierarchy, reveal large performance differences across task families, and show that observation interface design has a measurable effect on learnability. Together, the environment and these baselines define a practical starting point for RL research on abstract reasoning: future algorithms, architectures, and adaptation methods can be evaluated against concrete reference curves on a platform fast enough to support systematic comparison.
